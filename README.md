# 🐵 Magic Monkei

Nintendo Switch homebrew application that allows users to easily install **save files** and **Brazilian Portuguese (pt-BR) translations** for supported games directly from their Nintendo Switch.

Magic Monkei simplifies the process of applying community-created content without requiring users to manually locate, organize, or transfer files.

---

# 📦 Installation Guide

## Method 1 — DBI Installation (Recommended)

### 1. Download Magic Monkei

Download `Magic Monkei.nsp` to your computer.

### 2. Launch DBI

Open **DBI** on your Nintendo Switch.

### 3. Connect via USB

Connect your Nintendo Switch to your computer using a USB-C cable.

### 4. Start MTP Responder

Inside DBI, select:

```text
Run MTP Responder
```

Your computer will detect the Nintendo Switch and expose several virtual folders.

### 5. Open SD Install

On your computer, open the folder named:

```text
SD Install
```

### 6. Copy the NSP

Drag and drop:

```text
Magic Monkei.nsp
```

into the **SD Install** folder.

### 7. Automatic Installation

DBI will immediately begin installing the NSP.

Wait for the installation process to complete.

### 8. Launch Magic Monkei

Once installation finishes, Magic Monkei will appear on your Nintendo Switch home screen.

---

## Method 2 — Manual Installation

### 1. Download Magic Monkei

Download `Magic Monkei.nsp` to your computer.

### 2. Copy to SD Card

Copy the file to your Nintendo Switch SD card inside the following folder:

```text
/switch
```

### 3. Insert SD Card

Insert the SD card back into your Nintendo Switch.

### 4. Open an NSP Installer

Launch your preferred NSP installer, such as:

- DBI
- Awoo Installer
- Goldleaf
- Any compatible NSP installer

### 5. Install Magic Monkei

Navigate to:

```text
/switch/Magic Monkei.nsp
```

and install the application.

### 6. Launch

Once installation is complete, Magic Monkei will appear on your Nintendo Switch home screen.

# ✨ Features

## 💾 Save Manager

Browse and install save files for supported Nintendo Switch games.

- Community-created save files
- Organized game library
- Automatic save deployment
- Easy save replacement

# 🚀 Why Magic Monkei?

Installing saves and translations manually often requires:

- Downloading files from multiple websites
- Organizing folders manually
- Copying files to the correct locations
- Managing game-specific structures

Magic Monkei automates this process and provides a centralized experience directly on the Nintendo Switch.
